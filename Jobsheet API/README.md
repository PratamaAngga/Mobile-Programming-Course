# Flutter Learning Projects / Proyek Pembelajaran Flutter

> A collection of Flutter projects built as part of a structured learning journey in mobile application development.
>
> Kumpulan proyek Flutter yang dibangun sebagai bagian dari perjalanan belajar terstruktur dalam pengembangan aplikasi mobile.

---

## Projects / Daftar Proyek

| No | Project | Description / Deskripsi | Tech Stack |
|----|---------|--------------------------|------------|
| 1 | `belajar_login_firebase` | Firebase Authentication (Login & Register) | Flutter, Firebase Auth |
| 2 | `belajar_weather_app` | Simple Weather App with Open-Meteo API | Flutter, Dio, Open-Meteo API |
| 3 | `weather_app_with_login` | Weather App integrated with Firebase Authentication | Flutter, Firebase Auth, Dio, Geolocator, Geocoding |

---

## Learning Objectives / Tujuan Pembelajaran

- Memahami konsep dasar pengembangan aplikasi mobile menggunakan Flutter
- Mengimplementasikan autentikasi pengguna menggunakan Firebase Authentication
- Mengonsumsi REST API eksternal menggunakan package Dio
- Mengintegrasikan layanan lokasi (GPS) ke dalam aplikasi Flutter
- Menggabungkan beberapa layanan eksternal dalam satu aplikasi yang utuh

---

## Folder Structure / Struktur Folder

- Folder Docs = untuk menyimpan hasil screenshot atau dokumentasi penting tiap project
- Folder Docs/"nama-projek" = untuk menyimpan hasil akhir project baik yang berhasil ataupun error
- Folder Src = untuk menyimpan kode project
- File Readme = untuk penjelasan dan/atau laporan terkait projek

## Prerequisites / Prasyarat

Pastikan lingkungan pengembangan berikut telah terpasang sebelum menjalankan proyek:

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (v3.x atau lebih baru)
- [Dart SDK](https://dart.dev/get-dart) (sudah termasuk dalam Flutter SDK)
- [Android Studio](https://developer.android.com/studio) atau [VS Code](https://code.visualstudio.com/)
- [Firebase CLI](https://firebase.google.com/docs/cli)
- [Node.js](https://nodejs.org/) (dibutuhkan untuk Firebase CLI)
- Akun [Firebase](https://firebase.google.com/)
